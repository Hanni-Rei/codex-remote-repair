# Codex Remote 修复方案

Windows 桌面版 Codex Remote 重复后端单实例冲突的排查、修复与验收方法。

## 完整方案

[Codex-Remote修复方法-重复后端冲突-20260915.md](Codex-Remote%E4%BF%AE%E5%A4%8D%E6%96%B9%E6%B3%95-%E9%87%8D%E5%A4%8D%E5%90%8E%E7%AB%AF%E5%86%B2%E7%AA%81-20260915.md)

适用症状：电脑只打开一个 Codex 窗口，手机 Remote 却提示“已在另一个应用中打开”，且进程与日志检查确认存在重复后端。

方案包含故障证据、排查步骤、完整退出与重新启动的方法、验收标准和复发记录模板。

> 本方案整理于 2026-09-15，依据 2026-08-25 的历史修复案例。使用前需核对当前版本、进程和日志，不能保证永久不复发，也不适用于所有 Remote 连接故障。
